DETRÁS DEL PROYECTO

Hola, soy Rodrigo.

Lulexia es un proyecto de Rodrigo Ayala para facilitar la lectura a personas con dislexia y a quienes se benefician del apoyo visual y auditivo.

¿Tenés una idea, una consulta o encontraste algo para mejorar? Me gustaría escucharte.

Sobre esta versión

El proyecto disponible en este repositorio está desarrollado para iPad. La disponibilidad en otras plataformas se informará cuando exista una versión publicada. Esta web no ofrece todavía un enlace de descarga en Google Play.

Lulexia es una herramienta de apoyo a la lectura. No diagnostica ni trata la dislexia y no reemplaza el acompañamiento de profesionales.
